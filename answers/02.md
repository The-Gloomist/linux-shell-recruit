# Task 02 Answer

`./tools/recruit-info` 使用明确的相对路径，Shell 会按照这个路径直接找到并执行文件，不需要在 `PATH` 中搜索。

直接输入 `recruit-info` 时没有指定路径，Shell 会根据 `PATH` 环境变量中的目录依次查找可执行程序。由于项目的 `tools` 目录不在当前 Shell 的 `PATH` 中，所以直接输入 `recruit-info` 会提示 `command not found`。

输入 `ls` 时，Shell 会先进行命令解析。通过 `command -v ls` 和 `type -a ls` 可以看到，当前 Shell 中 `ls` 是 alias，会展开为 `ls --color=auto`；随后 Shell 根据 `PATH` 查找真正的 `ls` 程序，我们实际看到它位于 `/usr/bin/ls` 和 `/bin/ls`。执行 `ls --color=auto` 可以正常列出当前目录内容。
